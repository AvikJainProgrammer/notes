## 4. Local Wispr Flow alternative

- Voice dictation that runs locally and doesn't use up API tokens.
- **Repo:** `~/Documents/projects/localflow`
  ([github](https://github.com/AvikJainProgrammer/localflow), private), started 2026-10-04.
  - **Dictation:** hold Right ⌥ to dictate into any app. Whisper large-v3-turbo on MLX → Qwen 2.5 3B on Ollama for cleanup → pasted with ⌘V. Notes, Code and Raw modes, plus a menu-bar icon. Run it with `./run.sh`.
  - **Agent mode:** talk to a local assistant (qwen3:8b) that finds, reads, creates, edits, moves and deletes files in a folder, confirming every change. Run it with `./run.sh agent <folder>`.
  - Open issues are in the repo's `TODO.md`.
- Related: `~/Documents/projects/voicekit`
  ([github](https://github.com/AvikJainProgrammer/voicekit)), a reusable voice recording, transcription, phonetic matching and fuzzy matching toolkit.

# Learning objectives

## Programming

1. **Master Python fundamentals:** the basics and also niche topics such as metaclasses.
2. **Then go beyond the language:** design patterns, fundamentals of software architecture, and building different kinds of applications.
3. **How to learn:** have Claude write the code, then dissect and understand what it created, using the DAPPL framework (`learning_framework/dappl.md`) and other frameworks. Given today's coding ecosystem, prioritise "AI writes it → I understand it" over writing everything from scratch.
4. **Game development with LLMs:** build games with the help of LLMs, then study the architecture and design of the games they create (see `learning_framework/dissections/first_pacman_godot.md`).
5. **Testing, debugging and code review:** the skills that let me trust code Claude writes, alongside DAPPL.
6. **Computer science fundamentals:** operating systems, networking, databases, data structures and algorithms. These support both the architecture goal and the close-to-the-metal goal, and they're what let me use AI safely (see `learning_framework/conversations/to_summarise_disection_framework.md`).
7. **Running AI models locally:** how to run, tune and evaluate local models (Qwen, Whisper, etc.). Supports the kids' teaching tool, the Wispr Flow alternative and `handwriting-capture`.
